# Changelog

## 0.1.0 (in progress)

- Repo set up: packwiz pack, server layer, build and test tools.
- Mod list drafted in `mods.txt`; not yet boot-tested.
- Quest book (FTB Quests): Briefing, Gears & Metals, March of Industry 1-5, Into the Unknown 1, 2, 2.5, Logistics. Generated by `tools/questgen/build_quests.py`.
- Research locks (Chapters): andesite, alloy, brass, electricity, exotic, flight, logistics. Crafting is locked and recipes are hidden in JEI until researched; items can still be held and traded.
- Nether and End locked behind server-wide unlocks (`/skybound unlock nether|end`).
